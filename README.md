# MacroBase

> **⚠️ WORK IN PROGRESS**
> This repository and its associated web interface are currently under active development. Files, macro structures, and deployment scripts are subject to change without notice.

MacroBase is a curated collection of Klipper macros maintained by Kanrog Creations. 

Instead of manually digging through raw configuration files, MacroBase utilizes a GitHub Actions workflow to automatically generate a user-friendly web interface. Through the website, users can browse categorized macros, select the specific functionalities they want for their 3D printer, and instantly download a custom ZIP bundle containing the necessary `.cfg` files and a master `macros.cfg` include file.

### Features (In Development)
- **Single Source of Truth:** Macro documentation is parsed directly from the `.cfg` files.
- **Automated Web Interface:** Browse and select macros visually.
- **Custom Bundle Generation:** Download only the macros you need with one click.
